# 🌾 MineCrops App (Flutter)

A simple Flutter app and a smart farming companion, designed to empower farmers, students, and small planters with clear, reliable, and easy-to-understand crop information. It helps users make informed decisions to save on inputs, increase yield, and farm smarter.

---

## 🚀 Key User Features

- 🏠︎Homepage Dashboard

- 🔍Intuitive Search

- 🌐Categorized Browsing

- 🌾Comprehensive Crop Profiles

- ℹ️About App Section

---

## 🛠️ Technical Features

These features highlight the technology used and the underlying capabilities of the project:

- Flutter Cross-Platform Framework: Built using Flutter, allowing for native deployment on Android (APK) and web (Netlify).

- Modular Component Design: Organized UI with dedicated sections for Categories, Common Crops, and All Crops to ensure clean code and easy maintenance.

## 📲 Install on Android (APK)

To install the full native version of minecrops on your Android phone or tablet:

### 1. Download the APK

Click the link below to download the compiled Android application package. This file is hosted securely on Google Drive.

⬇️ https://drive.google.com/drive/folders/12I51_nmSblpAO3IPT7ZdRFltclcg-9wL?usp=drive_link


### 2. Allow Installation from Unknown Sources

Since this app is not installed from the official Google Play Store, Android requires you to permit "sideloading."

Go to your device Settings.

Search for "Install unknown apps" or navigate to Security/Privacy settings.

Locate the app you used to download the APK (usually Chrome or your device's Files app) and enable the "Allow from this source" toggle.

### 3. Install the App

Open your device's File Manager app.

Navigate to your Downloads folder.

Tap on the downloaded file "app-release.apk" and select "Install" when prompted.
